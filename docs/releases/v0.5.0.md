## What's new

- **A new desktop listening space:** smoky plum backgrounds, rose accents, translucent surfaces, softer typography, and updated music, settings, sharing, account and device panels.
- **Desktop discovery layout:** compact header search, grouped sidebar navigation, a spotlight with music picks, a dedicated Now playing/Up next column, and playback controls across the bottom. Layouts adapt to smaller windows and Android.
- **Play directly from Home:** click an Up next track to select it without navigating away or rebuilding the queue. Remote playback uses the host's queue entry IDs and respects transport/queue permissions.
- **Search from anywhere in the app:** header search remains available in settings and opens music results while preserving the submitted query.
- **Experimental Android Google library connection:** native Google Play services authorization replaces the blocked embedded account dialog for read-only YouTube playlist access. Browse private playlists and additional pages, restore authorization, and disconnect/revoke access. Tokens stay in native Android code.
- **Fresh README screenshots and setup instructions:** see the new desktop theme, layout, search and preferences, plus the Android OAuth registration guide.

## Android setup and limits

Google library access requires a Google Cloud project with YouTube Data API v3 enabled, an Android OAuth client matching the APK's package (`io.ytmlisten.desktop`) and signing SHA-1, and consent-screen access for your account. Follow [the setup guide](https://github.com/evoziosk/ytm/blob/v0.5.0/docs/android-google-sign-in.md). The native error dialog can copy the installed APK's exact registration details.

The release APK uses a test signing key. CI/test APK certificates can differ from local builds and future releases: register the certificate of the APK you actually install. Reinstallation may be needed when signing keys change. Live Google consent, restoration, private-playlist access and background playback still require physical-device acceptance. This connection does not sign in the Music playback WebView or enable authenticated Music/Premium playback.

## Downloads and updating

The release includes Windows EXE/MSI, macOS DMG, Linux AppImage/DEB, an experimental Android arm64 APK, and `SHA256SUMS.txt`. Verify downloads against the checksum file. Fully quit YTM Listen from the tray before installing the Windows update over your current version.

Desktop installers are unsigned. Windows is the primary verified development target; native macOS/Linux behavior still needs platform testing. The Windows virtual microphone remains a preview requiring an installed virtual audio cable and additional hardware acceptance.
