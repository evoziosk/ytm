## What's new

- **Windows virtual microphone preview:** route this app's music through an installed virtual audio cable, with an optional physical microphone, separate levels, meters, peak protection, and tray mute/stop controls. Microphone capture starts off and requires explicit opt-in.
- **Shared playback controls:** pair a phone, browser, or another desktop with a host over LAN or the configured relay; manage permissions, search, and control its queue. Listen Together remains available for synchronized playback on separate devices.
- **Experimental Android arm64 APK:** evaluate the app interface and remote controller. Includes foreground playback infrastructure, media controls, and QR pairing.
- **Build improvements:** cross-platform CI now includes the Android APK, and tagged releases include all five desktop installer formats plus the experimental APK and SHA-256 checksums.

## Setup and known limits

- Virtual microphone routing requires Windows build 20348 or later and an existing virtual audio cable such as VB-CABLE. Choose **CABLE Input** in YTM Listen and **CABLE Output** as the microphone in the receiving app. The app does not install a driver or change your system's default devices.
- App-scoped playback capture passed the native isolation check. Physical microphone/cable delivery, real end-to-end latency, and long-running hardware drift still need hardware testing.
- The Android APK uses a test signing key. Google sign-in in its embedded browser is currently blocked, and physical-device acceptance is pending. It is an evaluation build, not a production Android release; test-key upgrades may require reinstalling.
- Desktop installers are unsigned. Windows is the primary development platform; native macOS/Linux behavior still needs platform testing.
- Check each downloaded file against `SHA256SUMS.txt`. Install the newer desktop package over your existing installation to update.
